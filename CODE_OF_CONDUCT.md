# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be respectful, assume good faith, and keep disagreement about the
work rather than about the person doing it.

Report unacceptable behaviour to `cassiojonesdhein@gmail.com`. Reports are
handled confidentially.
